# ScanCrypt

**ScanCrypt is now distributed as a signed Windows application, not as a Python package.**

Download the latest signed release:
https://github.com/ironsightscyber/scancrypt/releases/latest

This PyPI entry is a pointer only. Installing it does not install the scanner; it simply
directs you to the official signed download. ScanCrypt finds and extracts the parts of a
ransomware-encrypted file that were never actually encrypted. It is a product of IronSights.
